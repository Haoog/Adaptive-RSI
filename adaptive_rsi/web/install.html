打开工作台

Android 安装

用 Chrome 打开本页，点击安装按钮；也可在浏览器菜单选择“安装应用”或“添加到主屏幕”。

iPhone / iPad 安装

用 Safari 打开本页，点击分享，选择“添加到主屏幕”，再点击“添加”。从主屏幕打开后可能需要重新登录。

先连接运行机器

手机无法访问电脑的 localhost。先在运行机器配置 HTTPS 访问地址，再在手机打开该地址。登录链接包含凭据，只在自己的设备上使用。

手机连接配置说明

安装方式

这是可安装的 Web 应用（PWA）。安装由浏览器完成，无需 APK 或 App Store 下载。使用时需要连接运行机器；当前页面不提供离线项目数据。

Note: after installation the app keeps its Chinese name on the home screen; the interface language still follows your choice here.
