# Live validation

[简体中文](LIVE_VALIDATION.md) | **English**

Automated checks use isolated local protocol fixtures. Use the following procedure to retain evidence for real providers and projects. A readable directory does not establish working inference.

1. Add an official API, gateway or local service in Model Center and fetch its directory. Keep credentials in Keychain, session memory or environment variables, never project files, screenshots or logs.
2. Explicitly test each model and reasoning effort you intend to use. This may incur charges and counts against the call budget. Check the effort-specific tool result, tokens, duration and failure reason; other efforts need separate tests.
3. Register an isolated Git test project and leave it paused. Configure a reproducible failing acceptance check and record the baseline commit. Assign planning, implementation and review routes, allowing enough calls for tool round trips.
4. Enqueue a narrowly scoped real defect and enable the project. Inspect value evidence, scope, frozen checks, independent acceptance and code review. On failure, inspect reasons, retries and retained artifacts.
5. Inspect the local patch and original repository. Confirm tasks and model usage remain project-scoped. Validation needs no PR; delivery still requires separate approval for that candidate.

Record provider, protocol, model ID, effort, runtime version, baseline, run ID, acceptance/review outcomes, returned usage and time. Missing provider token usage can understate estimates. Estimates are not invoices or strict monetary budgets.

Validate authentication failure, rate limiting and recovery separately. Three consecutive provider outages pause inference for that project and connection version. Check configuration and explicitly resume. Tool-format, budget and code-check failures do not increment provider outage counts.

One successful task establishes only that scenario. To evaluate strategy improvement, compare stable and candidate strategies on fixed, independent tasks using success, review and cost outcomes. Tasks used to tune the strategy cannot serve as independent evidence.
